# Templates Repository

A collection of custom web templates, landing pages, and static UI components built for various business niches. All projects are structured cleanly and documented in English as a universal standard.

## Included Projects

- **armonia_alma**: A holistic and mystic business landing page featuring a clean visual style and responsive layout.

## Technologies Used

- HTML5 / CSS3
- Modern Web Design Standards

## Purpose

To organize, maintain, and showcase foundational web templates for future local and modern software developments.
